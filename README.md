# 🚀 Hisham Alsayed - Advanced Frontend Portfolio

مرحباً بك في المستودع الرسمي لمشروعي البرمجي المتكامل. هذا المشروع عبارة عن منصة شخصية متطورة تتكون من 5 صفحات مترابطة، تم بناؤها بأعلى معايير هندسة واجهات المستخدم لتوفير تجربة سلسة، تفاعلية، وآمنة.

## مميزات المشروع (Features)
* **السيرة الذاتية (Portfolio):** واجهة تعريفية حديثة مع دعم كامل للوضع الداكن/الفاتح (Dark/Light Mode).
* **المدونة الذكية (Blog):** نظام فلترة ديناميكي للمقالات باستخدام JavaScript بدون إعادة تحميل الصفحة.
* **متجر العتاد (Hardware Store):** نظام سلة مشتريات فوري مع حساب الإجمالي وحفظ البيانات في المتصفح (LocalStorage).
* **الحاسبة الرقمية (Smart Calculator):** معالج رياضي آمن مبني بأسلوب (State Machine) خالي من أخطاء `eval()`.
* **نموذج الاستشارات (Contact Form):** نظام تحقق فوري (Live Validation) لضمان صحة المدخلات.

## 🛠️ التقنيات المستخدمة (Technologies)
* **HTML5:** هيكلة دلالية (Semantic Web).
* **CSS3:** متغيرات (CSS Variables)، Grid، و Flexbox لتصميم متجاوب (Responsive).
* **JavaScript (ES6):** معالجة منطقية نقية (Vanilla JS) بدون الاعتماد على مكتبات خارجية ثقيلة.
* **Bootstrap 5:** لتسريع بناء الشبكات والتجاوب.
* **AOS:** حركات وتأثيرات الانزلاق عند التمرير.
